    Beginner command sheet

    • pwd — show the folder you are in
    • ls — list files in this folder
    • cd Documents — move into the Documents folder
    • cd .. — go up one folder
    • mkdir project — create a new folder named project
    • cp file.txt backup.txt — copy a file
    • mv old.txt new.txt — rename or move a file
    • cat notes.txt — print a text file
    • clear — clean the terminal screen
